## Stop and rollback

If a protected check fails, preserve evidence and investigate; do not advance manually or rerun blindly. A failed pre-deploy can leave the old game active. Confirm actual authorized deployment metadata before recovery.

For a code regression, prepare a reviewed revert PR, complete exact-commit push CI and use the same protected release with a fresh backup and owner approval. Phase 5 adds no schema downgrade. Retain command receipts, real purchases, paid lots, combat/XP and all financial history. Reverting code does not cancel legitimate committed activity; use the activation plan's safe OFF deployment if necessary.

A live database restore is a separate, explicitly authorized incident operation. Verify ciphertext/manifest checksums, independently decrypt/archive-check with the original offline key, restore/rehearse only on an isolated independent database, and review legitimate intervening play before any live recovery decision. Never reset/reseed or restore a pre-activation dump merely to erase bot development.
