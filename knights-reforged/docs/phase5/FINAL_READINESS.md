## Blockers versus alpha limitations

**No code or preservation blocker is identified in the completed checks.** Owner final approval/merge and the resulting production commit's complete successful **push** CI remain mandatory release gates. Real service identities/settings, current backup/key readiness, private database connectivity, deployment configuration and physical devices have **not** been inspected here. Missing/failed protected checks, unreviewed base/head changes, unknown staged Railway changes or a live preflight failure block promotion; resolve them without bypassing guards.

**Activation is a separate hold**, even after a successful OFF release: the owner must approve the flag states, confirm an authorized private read-only monitoring channel and storage/latency headroom, and accept the restart-based stop latency. Existing server logs report fixed failures, not successful per-tick counters; `/healthz` proves neither feature state nor economic conservation. This task does not create a new monitoring/admin endpoint or activate PR #13.

Documented alpha limitations (no policy changes to conceal them):

- Settlement batching cuts SQL calls **43.8% / 62.9%** in the original/mature fixtures; it does not reduce durable history. The quiet purchase month produced **6.69 million settlement rows**. Local execution medians exclude COMMIT/private-network latency; real database/WAL/storage/backup capacity remains unverified. Duel history adds up to **900 scheduled initiations/day** across 450 bots (usually fewer); losing attacks count toward that activity limit.
- The quiet month improved selected gear for **444/450 bots**, but **68** bought nothing in its final week. Starter portfolios can stall on the two-hour-income budget; gear selection favors offense. Acquisitions consumed only **0.47%** of generated Land credits; this is conservative development, not an inflation sink.
- The single duel sample's attacking win rate was **35.4%**. Bots can wait for resources, lose, carry depleted purses, earn 1 XP, or miss slots. Natural Health/purse changes can affect human availability/loot; provisional repeat floor, modest player raids and short duel samples do not prove worst-case farming balance.
- More replicas share the same receipt/pressure limits, but introduce extra reads and contention. There is no production latency result, selective rollout or instant feature kill switch. Preserve one game replica for the initial authorized rollout.
- Physical Android/iPhone audio/output/suspension checks remain owner alpha checks. No UI/audio/art changes or APK work are included in Phase 5.
