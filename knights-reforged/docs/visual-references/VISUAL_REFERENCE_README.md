# Kingdom Come — Historical Visual Reference Archive

This archive contains user-supplied original-game screenshots. These are historical design and gameplay references, **not approved requirements or proof of current implementation**.

Reference topics include original Kingdoms Live and Knights Reforged: home, profile stats and income, quests, armory, land, army/recruitment, battle results, bounty kills and activity feeds, social comments, skills and UI styling.

## Approved interpretation
- Preserve the original compact, readable five-tab identity; avoid cosmetic redesign for its own sake.
- Profile layout: Kills, Deaths, Quests / Battles Won, Battles Lost, Initiated for; then Total Income, Upkeep, Net Income; then equipment.
- Kills are successful bounty claims; deaths are successful bounty claims against the player; ordinary victories are separate.
- Historical values and restrictions are not automatically rules for the new game.
- The original images should remain intact. Review them manually before using as design evidence.

The image index preserves original filenames; a future annotated edition can categorize each image individually.
