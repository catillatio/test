## Independent native restore rehearsal

[Evidence](independent-restore.json) records an actual native custom archive restored into a **different PostgreSQL cluster**, not merely another schema or database on the source cluster. The rehearsal uses synthetic humans, a saved session, paid inventory lots, Land, ordinary ledger/XP and all 450 fixture bots. It verifies all 71 pre-upgrade tables, upgrades 023→024, compares every existing business row, replays migration, reconstructs state and retains the saved session. Its migration SHA-256 ties the evidence to the final additive SQL.

```sh
# TEST_DATABASE_URL must name a passwordless 127.0.0.1 disposable *_test cluster.
# E2B_PG_SERVER_BIN: local PostgreSQL 18 initdb/pg_ctl/postgres directory.
# E2B_PG_CLIENT_BIN: PostgreSQL 18 pg_dump/pg_restore directory.

```

The script creates only a uniquely named synthetic source database and a temporary local cluster on port 5542, verifies cluster identities differ, and removes its own database/data/archive in `finally`. It neither connects to live data nor accepts a remote target. Local native evidence is a preservation rehearsal; the existing final CI worker separately verifies the full encrypted recovery chain.

## Simulation assumptions and limits

[progression.json](progression.json), [economy.json](economy.json), [rarity.json](rarity.json), [population.json](population.json) and [catalog.json](catalog.json) are generated by `scripts/level100-e2b.ts`. The finite-resource adapter reuses E1's model in a separate source file, substituting the actual Approach-A catalog, leaving all archived E1 inputs/results unchanged. It conserves total synthetic currency, Mana, Stamina and Health; accounts for session windows, downtime, recruitment pacing, actual gear costs, progressive Land, upkeep/reserves/arrears, finite opponent wallets/Health, victories/losses, unchanged reward tapering, skill allocation and real level-up refills. No rare item is assumed when calculating leveling speed.

Three deterministic seeds cover intensive 8h, regular 90m, four-visit 2h, current450 and half-availability scenarios for up to 120 days. These do not measure live latency or simulate a multi-human persistent economy. The E3 cohort and capital are hypotheses awaiting separate review. Build/treasury stress checks extend to levels 200/500 without adding content there.

Rarity calculations sum binomial tails directly to avoid subtractive cancellation. 5/10/15 eligible daily completions are explicit post-71 sensitivities, constrained by 5-minute Mana recovery, quest costs, session timing and saved capacity; they are not assumed available during levels 1–70. The actual paced pre-100 trial counts are recorded separately. Multiple items on the level-100 quest use independent draws. No undocumented pity or drop boost exists.
