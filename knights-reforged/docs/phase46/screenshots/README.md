# Phase 4.6 mobile verification

These are actual EJS/Chromium captures of synthetic human characters in an isolated local PostgreSQL realm, not live player data or generated mockups. All existing equipment/property art is reused. The supplied remake reference informed the compact loadout presentation; it does not verify original Storm8 combat formulas.

Screenshots use 390 × 844 CSS-pixel viewports; tall pages are captured in full. The fixed five-tab bar appears at its normal viewport position within a full-page capture. Some images show the optional tutorial while a new character learns; completed/skipped guides do not obscure ordinary play.

Mature combatants use explicit synthetic level/equipment/resource fixtures and the real combat transaction. The suite also checks Revenge Spirit, old equipment snapshots, no technical reward prose, keyboard-operated disclosures, reduced motion, five tabs, image loading and horizontal overflow.

Responsive checks: 320, 360, 375, 390, 393, 412, 430 and 1366 pixels; 56 visits; zero browser errors. [Browser evidence](../browser-verification.json). A separate real local TLS/Codespaces-shaped proxy verifies native secure sessions and POST Origins.

This is browser verification at Android/iPhone-sized dimensions, not physical-device, Safari/WebKit, Android WebView or APK verification. No live service was contacted. [Release/operator guide](../../../PHASE_4_6_RELEASE.md).
