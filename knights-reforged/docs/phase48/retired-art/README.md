# Retired runtime artwork

The three provenance manifests in this folder identify historical APK-derived files removed from `public/art` during Phase 4.8. Redistribution permission could not be established. Their bytes remain in Git history for audit, but are no longer served or packaged in the current public asset tree.

The active shared background, crest, navigation icons and approved Land illustrations use the documented original `public/art/land-review` and `public/art/remaster-ui` assets. Original catalog illustration sheets and placeholder SVGs remain intact. No original Storm8 screenshots or artwork were copied into new runtime assets.
